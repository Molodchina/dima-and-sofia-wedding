# Свадебный сайт-приглашение Дмитрия и Софьи

## Обновления
- пять акварельных интро-кадров с увеличенной длительностью;
- плавные переходы и кнопка пропуска;
- авторские иллюстрации интегрированы в основную страницу;
- церковь используется для блока венчания;
- танцующие гости — для welcome и банкета;
- собака с башней бокалов — для блока пожеланий;
- танцующая пара — в финальной секции;
- иллюстрация дома с бассейном сознательно не используется, чтобы не создавать ложное впечатление о месте проведения;
- RSVP и локальная admin-страница сохранены.

Откройте `index.html` или загрузите всю папку на статический хостинг.

- Добавлен адаптивный блок дресс-кода с палитрой, рекомендациями и двумя moodboard-референсами.
